## ما هي DataDoctor؟

تمنح DataDoctor MCP مساعد Claude مجموعة أدوات محلية ومحددة الصلاحيات لفحص الملفات، والتحقق البنيوي من الصيغ المدعومة، وتحليل ملفات CSV إحصائياً، واكتشاف الملفات المتطابقة، ومقارنة الإصدارات، وتشخيص الأخطاء، وتنفيذ عمليات تطبيع محدودة بعد موافقة صريحة.

المبدأ الأساسي:

> **كل تشخيص يجب أن يستند إلى دليل. وكل تعديل يحتاج إلى شرط مسبق ونسخة احتياطية. وكل إصلاح ناجح يجب أن يجتاز فحصاً بعد الكتابة.**

## الميزات

- فحص مجلدات محلياً ضمن مسارات يسمح بها المستخدم.
- حساب SHA-256 للملفات التي جرى فحصها.
- التحقق البنيوي من JSON وCSV وXML وZIP وSQLite وبعض ملفات UTF-8.
- اكتشاف الملفات المتطابقة بايتياً.
- مقارنة نسختين وإنتاج فرق نصي محدود للملفات الصغيرة.
- تحليل CSV وإرجاع إحصاءات مجمعة دون إعادة الصفوف أو العينات الخام.
- تشخيص منظم للأخطاء مع توضيح ما تم فحصه وما لم يتم فحصه.
- تطبيع JSON صالح مسبقاً أو CSV متسق بنيوياً، بعد تأكيد صريح وبصمة SHA-256 مطابقة.
- إنشاء نسخة احتياطية لا تستبدل نسخة موجودة، ثم فحص النسخة الجديدة قبل إعلان النجاح.
- ثلاثة MCP Prompts لتوجيه Claude إلى مسارات عمل قائمة على الأدلة.

## أدوات MCP

| الأداة | الوظيفة |
|---|---|
| `scan_data` | فحص مجلد مع بيان التغطية والتجاوزات |
| `inspect_file` | فحص ملف وحساب SHA-256 |
| `detect_corruption` | التحقق البنيوي من الصيغ المدعومة |
| `find_duplicates` | اكتشاف الملفات المتطابقة |
| `profile_dataset` | تحليل CSV وإحصاء أعمدته وصفوفه |
| `compare_versions` | مقارنة ملفين |
| `diagnose_errors` | تشخيص الأخطاء وإرجاع أدلتها |
| `verify_integrity` | مقارنة الملف ببصمة موثوقة اختيارية |
| `generate_report` | إنشاء تقرير فحص منظم |
| `repair_data` | تطبيع JSON/CSV صالحين مسبقاً بشروط أمان |

## الأمان وحدود الفحص

- جميع الأدوات للقراءة فقط باستثناء `repair_data`.
- يجب تحديد مجلد واحد أو أكثر عبر `--root`.
- تُرفض المسارات خارج المجلدات المسموح بها، وتُرفض الروابط الرمزية في المسار المطلوب.
- الفحص محدود بعدد الملفات والعمق والحجم والزمن.
- لا تُعتبر الملفات التي لم تُفحص سليمة؛ تظهر كـ `unchecked` أو `skipped`.
- الإصلاح لا يعيد بناء بيانات تالفة ولا يخمّن القيم الناقصة.
- يتطلب الإصلاح `confirm: true` وبصمة `expected_sha256` مطابقة، وينشئ نسخة احتياطية ثم يتحقق من النتيجة.
- SHA-256 يحدد البايتات، لكنه لا يثبت المصدر أو الأصالة دون بصمة موثوقة للمقارنة.

DataDoctor ليست أداة مكافحة برمجيات خبيثة، ولا نظام استعادة مضمون، ولا بديلاً عن قواعد تحقق دلالية متخصصة.

## المتطلبات

- Node.js 20 أو أحدث.
- Python 3.10 أو أحدث.
- Claude Desktop أو Claude Code مع دعم MCP المحلي.

لا تحتاج بيئة Python إلى تثبيت حزم إضافية؛ المحرك يستخدم المكتبة القياسية.

## التثبيت

```bash
git clone https://github.com/ayoubissa344-ship-it/datadoctor-mcp.git
cd datadoctor-mcp
npm install
npm run build
npm run test:all
```

## ربط Claude Desktop

بعد البناء، أضف الخادم إلى `claude_desktop_config.json` مع استبدال المسارات بأخرى مطلقة على جهازك:

```json
{
  "mcpServers": {
    "datadoctor": {
      "command": "node",
      "args": [
        "/absolute/path/to/datadoctor-mcp/dist/index.js",
        "--root",
        "/absolute/path/to/folder-to-inspect"
      ]
    }
  }
}
```

يمكن إضافة أكثر من مجلد بتكرار `--root` والمسار. امنح Claude أضيق نطاق ممكن، ثم أعد تشغيل Claude Desktop.

## ربط Claude Code

```bash
claude mcp add --transport stdio datadoctor -- node "$PWD/dist/index.js" --root "$HOME/Documents/DataToInspect"
```

| الحد | القيمة الافتراضية |
|---|---:|
| الملفات في الفحص | 1,000 |
| عمق المجلدات | 8 |
| حجم الملف للتحقق البنيوي | 25 MiB |
| إجمالي بايتات الفحص | 512 MiB |
| مهلة عملية Python | 45 ثانية |
| صفوف CSV للتحليل | 100,000 |

يُعلّم التقرير الفحص بأنه جزئي عند الوصول إلى أي حد، ويذكر سبب التوقف.
